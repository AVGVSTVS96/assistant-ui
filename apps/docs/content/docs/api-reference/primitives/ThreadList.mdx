# ThreadListPrimitive

Provides primitives for building a thread list UI. For a complete example, see the [ThreadList guide](/docs/guides/thread-list).

## Anatomy

```tsx
import { ThreadListPrimitive } from "@assistantui/react";
import { MyThreadListItemComponent, MyLoadingSkeleton } from "./MyCustomComponents"; // Placeholder

const ThreadList = () => (
  <ThreadListPrimitive.Root>
    <ThreadListPrimitive.If isLoading={true}>
      <MyLoadingSkeleton message="Loading threads..." />
    </ThreadListPrimitive.If>
    <ThreadListPrimitive.If isLoading={false}>
      <ThreadListPrimitive.Items components={{ ThreadListItem: MyThreadListItemComponent }} />
    </ThreadListPrimitive.If>
    <ThreadListPrimitive.New>
      <button>New Thread</button>
    </ThreadListPrimitive.New>
  </ThreadListPrimitive.Root>
);
```

## API Reference

### Root

The root container for all parts of the thread list.

This primitive renders a `<div>` element unless `asChild` is set.

### New

A button or trigger to create a new thread. When clicked, it switches to a new thread context.

This primitive renders a `<button>` element unless `asChild` is set.

<ParametersTable
  type="ThreadListPrimitiveNewProps"

      description: "Whether to render as a child component.",

    },
  ]}
/>

### If

Conditionally renders its children based on the thread list's loading state.

<ParametersTable
  type="ThreadListPrimitiveIfProps"
  parameters={[
    {
      name: "isLoading",

      description:
        "If true, children render if the thread list is loading. If false, children render if the thread list is NOT loading.",
    },
  ]}
/>

**Example**

```tsx
import { ThreadListPrimitive } from "@assistantui/react";
import { MyLoadingSkeleton, MyThreadListItemComponent } from "./MyCustomComponents"; // Placeholder

<ThreadListPrimitive.If isLoading={true}>
  <MyLoadingSkeleton message="Loading threads..." />
</ThreadListPrimitive.If>
<ThreadListPrimitive.If isLoading={false}>
  <ThreadListPrimitive.Items components={{ ThreadListItem: MyThreadListItemComponent }} />
</ThreadListPrimitive.If>
```
