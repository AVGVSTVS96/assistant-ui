### `useThreadMessagesIsLoading`

A convenience hook to specifically access the message loading status of the current thread.

**Signature:**
```typescript
function useThreadMessagesIsLoading(options?: { optional?: boolean }): boolean;
```

**Returns:**
- `boolean`: `true` if messages are currently loading for the thread, `false` otherwise. Defaults to `false` if the thread context is not found and `options.optional` is true.

**Example:**
```tsx
import { useThreadMessagesIsLoading } from "@assistant-ui/react";
import { MyLoadingSpinner } from "./MyCustomComponents"; // Placeholder

function MyThreadComponent() {
  const isLoading = useThreadMessagesIsLoading();

  if (isLoading) {
    return <MyLoadingSpinner />;
  }

  // Render thread content...
  return <>...</>;
}
```

### `useThreadViewport`

Manage thread viewport state (e.g., scrolling):

```tsx
import { useThreadViewport } from "@assistant-ui/react";

const threadViewport = useThreadViewport();
const isAtBottom = useThreadViewport((m) => m.isAtBottom);
```
